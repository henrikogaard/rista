# Pre-GPUI documentation archive

These documents record plans, design notes, QA notes, and changelog material from before Rísta became the Rust/GPUI application described in the [active documentation index](../../README.md).

They are retained as history, not current product guidance. The commands, source paths, renderer architecture, platform claims, feature lists, and release instructions in them may no longer apply. Do not use an archived procedure to build, test, package, or change the current app. Relative links to archived documents remain useful where their targets are also archived; source links may point to removed files.

The archive contains the former architecture, architecture plan, next sprint, product roadmap, project board, release checklist, and test cases; the earlier worklog and design QA record; the former changelog; and eight dated plans/specifications under `superpowers/`.
